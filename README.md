# نظام العودة الطوعية للسودان — نسخة HTML + CSS + JavaScript + Excel

لا يحتاج هذا النظام إلى خادم أو MySQL. الواجهة بالكامل HTML/CSS/JS، والبيانات تُحفظ في ملف **Excel**.

## الملفات
```
index.html      الخطوة 1: الاسم، التلفون، الإيميل، الجنس، صورة الجواز  ← التالي
step2.html      الخطوة 2: أسباب الرجوع + هل الرجوع باختياره (نعم/لا) ← إرسال
admin.html      واجهة المشرف
css/style.css
js/db.js        التخزين (IndexedDB) + قراءة/كتابة Excel
js/app.js  js/step2.js  js/admin.js
```

## التشغيل
1. افتح المجلد في **Chrome** أو **Edge** (مفضّل).
2. الأفضل تشغيله عبر خادم محلي بسيط حتى تشترك كل الصفحات في نفس التخزين:
   `python -m http.server 8000` ثم افتح `http://localhost:8000`
   (فتح الملفات مباشرة بالنقر المزدوج يعمل في Chrome/Edge، لكن Firefox قد يفصل التخزين بين الصفحات.)
3. عند أول دخول إلى `admin.html` يُطلب منك إنشاء كلمة مرور للمشرف.
4. مكتبة Excel (SheetJS) تُحمَّل من الإنترنت في صفحة المشرف. للعمل دون إنترنت نزّل `xlsx.full.min.js` وضعه في `js/` وعدّل وسم `<script>` في `admin.html`.

## كيف تُحفظ البيانات في Excel؟
المتصفح لا يستطيع الكتابة في ملف على جهازك دون إذن، لذلك هناك ثلاث طرق في لوحة المشرف:
- **ربط ملف Excel** (Chrome/Edge): تختار ملف `.xlsx` مرة واحدة، ثم يُحدَّث تلقائياً بعد كل تعديل، وعند فتح اللوحة.
- **تصدير Excel**: تنزيل نسخة كاملة بأي وقت (تعمل في كل المتصفحات).
- **استيراد Excel**: رفع ملف سبق تصديره لاستعادة الطلبات أو تحديث حالاتها (يطابق الطلبات بعمود «الرقم»).

## الجدولة وتعديل الجدول
من اللوحة: بحث وفلترة بالحالة، وفتح أي طلب لتغيير الحالة وتاريخ السفر والملاحظات أو حذفه. ويمكنك أيضاً تعديل الملف في Excel نفسه ثم استيراده.

## حدود يجب معرفتها
- البيانات تُحفظ في **المتصفح الذي ملأ النموذج**. لذلك يجب أن يعمل النموذج واللوحة على نفس الجهاز والمتصفح (مثل مكتب تسجيل). المستخدمون على أجهزة أخرى لن تصل طلباتهم إليك.
- صور الجوازات تبقى داخل المتصفح (يمكن تنزيل كل صورة من نافذة الطلب)، أما ملف Excel فيحتوي اسم الملف فقط لأن الخلية لا تتسع للصورة.
- حماية كلمة المرور محلية فقط، ولا تمنع من يملك وصولاً للجهاز من قراءة بيانات المتصفح. لأن الملفات حساسة (جوازات)، استخدم جهازاً موثوقاً.
- مسح بيانات المتصفح يحذف الطلبات: صدّر نسخة Excel احتياطية بانتظام.
